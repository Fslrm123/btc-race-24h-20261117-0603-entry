DipBuyer: a long-only dip-buying bot trading Coinbase Wrapped BTC (cbBTC) on 1-minute on-chain bars. It buys sharp intraday dips — the close at least 110 bps below the highest close of the last 45 bars — and sells on a 100 bps bounce from the entry close. One position at a time, full cash in, full position out. No shorts, no leverage, no randomness, no clock.

## Run it

```sh
node main.ts
```
